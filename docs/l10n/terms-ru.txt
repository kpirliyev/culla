Culla: Russian terms and conventions settled during translation (2026-11-12). New text must match.
Glossary: docs/localization.md. Decided on top of it:

sidecar: «файл XMP» in buttons, counts, headlines, second mentions; full «сопроводительный файл XMP»
  only where a sentence first explains the file (once per screen/paragraph). 1 файл XMP / 3 файла XMP /
  5 файлов XMP / из 5 файлов XMP.
unreviewed: sidebar group «Непросмотренные»; count «86 не просмотрено»; attributive «непросмотренные фото».
inspector: lower case («Показать инспектор»).
flag (detection) = пометка / помечать.  mark (decision, Mark Only) = отметить / «Только отметить».
Certain / Likely = «Точно» / «Вероятно» (in ёлочки as names).  undecided = без решения.
set (duplicates) = набор.  copy = копия.  exact copies = точные копии.  near-duplicates = почти одинаковые копии.
accept = принять.  stack review = просмотр серий.  duplicate review = просмотр дубликатов.  Start Reviewing = Начать просмотр.
keepers = оставленные фото.  rejects = отклонённые фото.  likely rejects = кандидаты на отклонение.
the apply = применение; Undo Apply = отмена применения / «Отменить применение…»; cancelled = отменено; stopped = остановлено;
  retry = «Ещё раз отменить применение».  Undo %@ = «Отменить: %@», Redo %@ = «Повторить: %@».
blown highlights = выбитые света.  crushed shadows = проваленные тени.  clipping = пересветы и провалы.
lens smudge = грязь на объективе.  cut-off face = обрезанное лицо.  accidental shot = случайный кадр.  weak shot = слабый кадр.
screenshot = снимок экрана.  main face = главное лицо.  background face = фоновое лицо.  subject = объект.
camera burst = серийная съёмка.  aesthetics = эстетика.  tile = плитка.  thumbnail = миниатюра.
selection = выбор / выбранное.  group = группа.  pane (compare) = панель.  item (file/folder) = объект.
presets: Мягкий / Сбалансированный / Строгий.  Settings panes: Глаза, Резкость, Сходство, Дубликаты, Экспозиция, Другое.
Keys sections: Решения, Навигация, Вид, Анализ, Файл и Правка.  Menus: Файл, Правка, Вид, Переход, Окно, Справка.
Zoom to 100% = Увеличить до 100%; Zoom to Fit = Вписать в окно.  units: с, мин, ч.
macOS names: Выбрать все, Отменить выбор, Убрать в Dock, Круговое переключение окон, Скрыть остальные, Завершить Culla,
  Переместить в Корзину, Пробел; modifier/navigation keys stay Latin.
Conventions: no gendered past tense for Culla; plural `other` = `many`; `one` forms must also read right for 21, 31…
  (no singular pronouns); localized names go after a colon or in «» so they are not declined;
  Go-menu items are noun phrases; switches read by VoiceOver: Включено / Выключено.
