Culla — Turkmen terms for the interface text
=============================================
Written after the package batch (480 entries) and the coordinator's rulings on it.
The app batch must use the same terms. The glossary in docs/localization.md stays binding;
this file adds what it does not cover and records the rulings that changed it.

RULINGS (override the glossary and the first draft)
---------------------------------------------------
1. sidecar            «XMP faýly» in buttons, counts, headlines and second mentions.
                      The full «XMP goşmaça faýly» only in the sentence that first explains the
                      file (at most once per screen or paragraph; never in a button or a count).
2. clear decision     «Karary aýyr» (hint: «karary aýyr»; count: «%lld suratyň kararyny aýyr»).
                      decision = «karar» everywhere. «bellik» = Culla's flag. «reňk belligi» = colour label.
                      Do not use «belgi».
3. Move to the Trash  «Sebede taşla»; results «Sebede taşlandy», «Sebede taşlanar», «Sebede taşlanan».
                      «geçir» stays for moves into _Rejected and other folders.
4. Make Best Pick     «Iň gowy kadr hökmünde saýla» (menu, Keys); hint «iň gowy saýla».
5. hide / show pick   «iň gowusyny gizle» / «iň gowusyny görkez».
6. score (Vision's or a detector's number)   «bal». «baha» means only the star rating.

Kept as drafted: apply = «ulan» / «Kararlary ulan»; shoot = «bukja», or «surata düşüriş bukjasy»
where it must be told apart from another folder; keep = «galdyr»; copy = «nusgala»;
Certain / Likely = «Şübhesiz» / «Ähtimal»; On / Off = «Ýakylan» / «Öçürilen»; hyphenated suffixes
on the app name (Culla-ny, Culla-dan), avoided by restructuring where possible.
